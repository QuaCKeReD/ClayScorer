How it works

  • Scores save automatically on this device as you tap. Each discipline keeps its own rounds.
  • Give a round a ground or event name to keep it in History, where you can reopen it later.
  • Works offline once loaded. On iOS/Android, use “Add to Home Screen” to install it.
  • Sign in (cloud button on any discipline page) to back up rounds to the server and use them on other devices.
